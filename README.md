  <h3 align="center">Новостной агрегатор</h3>

![image1](https://github.com/WSG434/langamenews/blob/main/public/images/preview.jpg?raw=true&#41;)

Новостной агрегатор на Symfony 8. Пользователи регистрируются через Telegram-подтверждение, читают новости из нескольких RSS-источников с полнотекстовым поиском и получают realtime-уведомления о событиях в системе.

## Функциональность

- **Регистрация и авторизация** — email + пароль, подтверждение 6-значным кодом через Telegram (RabbitMQ + retry)
- **Импорт новостей** — универсальный механизм адаптеров (RSS), консольная команда + cron, дедупликация по source+uid
- **Поиск** — AJAX с debounce 300ms, MySQL FULLTEXT
- **Источники** — пользователь включает/отключает источники в своей ленте
- **Realtime SSE** — toast-уведомления о входе, регистрации и импорте новостей без перезагрузки страницы
- **Админка** — EasyAdmin 4: пользователи, коды подтверждения, новости с фильтрами и пагинацией
- **Настройки** — включение/отключение личных Telegram-уведомлений
